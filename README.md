# 拾荒者クロニクル / Scavenger Chronicle

終わった世界で、拾った道具と小さな移動拠点を頼りに生き延びる、探索 × サバイバル × デッキ構築カードゲーム。プレイ可能版 **0.2.5**。

## 遊べるもの

- 個人は徒歩、移動拠点は燃料で別々に移動する。拠点に戻り、資源や装備を保管する。
- 探索は知覚＝発見箇所数、判断＝手札枚数、行動＝使えるカード枚数、実効＝判定D6数。道具補正を足して難易度を超えると回収できる。
- 戦闘は双方の行動列を計画した後、一括解決。同じ位置のカードを同時扱いにする。
- 知覚＝公開する敵予定、判断＝手札枚数、行動＝実行するカード枚数、実効＝攻撃の６面ダイス数。
- 頭HP・体HP・頭ST・体ST。６の出目は頭に当たり、体HPが尽きるとダメージが頭へ流れる。
- １アイテムに１〜３個の修飾子がつく。各修飾子には利点と欠点があり、効果を合算する。
- 装備を反映する主人公、敵３種、探索施設９種、カード17種、拠点設備５種。画像生成で制作した、太い黒輪郭・大きな頭と目・短い手足のトゥーン系ラスタ素材。
- 食事・飲み物・包帯・医療箱の回復アイテム10種、荷重、休息、設備追加、次の街への移動。
- 自動保存、JSONセーブの書き出し・読み込み。戦闘途中の手札・敵予定・乱数状態も保存する。
- PCの横長画面、スマホのフィールド／操作エリアの上下構成。スマホではHP・STを上部に表示し、戦闘の実行ボタンを下端に配置。

数値・カード効果・敵AIは初期調整段階。旧版の全機能を移植したものではなく、新しいゲームの土台です。詳細は [設計](docs/design.md) と [検証結果](docs/validation.md) を参照。

## 0.2.5 のPC探索表示修正

- 探索箇所には最低1行分の高さを確保。低い画面では中央欄を縦にスクロールでき、背景・クルマ・探索箇所・手札を確認して操作できる。
- 中央欄の内容が横にはみ出す問題も修正。探索箇所・手札の選択や地図の開閉後にも各欄のスクロール位置を保持する。

## 0.2.4 の戦闘アイテムと回復のバリエーション

- 戦闘中の「アイテム」から、携行品の使用をカードと同じ行動列に追加。1個＝1行動で、カードと合計して行動上限を使う。順番変更・取り消しが可能。使用枠でも敵は行動し、回復→攻撃の順で解決する。
- 追加時は予約だけ。実行した分だけ1個ずつ消費し、先の行動で戦闘が終われば後ろの品物は残る。拠点の在庫は戦闘で使えない。手札を引かなくても、所持する回復品を行動として使える。
- 回復は食事→体ST、飲み物→頭ST、包帯→体HP、医療箱→頭HPに分離。医療箱は体HPを回復しない。戦闘外でも同じ効果を使う。最大値まで回復し、HP回復による知覚・行動上限の増加は次ラウンドから反映。

| 種類 | 回復 | 特徴 | 重量 |
|---|---|---|---:|
| 保存食 | 体ST＋6 | 空腹−35 | 0.15 |
| 乾パン | 体ST＋4 | 空腹−25、渇き＋5 | 0.1 |
| 栄養バー | 体ST＋7 | 空腹−25 | 0.1 |
| 肉の缶詰 | 体ST＋10 | 空腹−45 | 0.3 |
| 飲料水 | 頭ST＋5 | 渇き−40 | 0.15 |
| ボトルのお茶 | 頭ST＋8 | 渇き−25 | 0.15 |
| 包帯 | 体HP＋6 | 布1つから作成 | 0.1 |
| 救急パッド | 体HP＋12 | 強めの体の手当て | 0.15 |
| 医療箱 | 頭HP＋3 | 頭の手当て | 0.15 |
| 高品質の医療箱 | 頭HP＋5 | 強めの頭の手当て | 0.3 |

- 食品・水・医療物資の探索でバリエーションを回収。種類ごとの重量で上限を判定。拠点への預け入れ・持ち出し、探索の回収結果モーダルにも対応。包帯は拠点で布1を消費して1時間で作り、保管後に持ち出す。休息には食事と飲み物のいずれの種類も使える。
- 新しい旅には包帯2を携行し、拠点にいくつかの回復品を用意。既存セーブでは新種類を0個で補完し、元の物資・予定・手札・乱数を保持。アイテムを予約した状態や解決後にも再読み込みできる。

## 0.2.3 の密着攻撃・回収結果・戦闘ダイス

- 通常武器6種の射程を0〜1に統一。「長すぎる」修飾は1〜2になり、長い武器の密着時には後退が必要。投石と敵固有武器の射程は維持。
- 探索判定モーダルに回収品のイラスト・名前・個数を追加。資源の一部回収や、荷重超過で回収できなかった品物も明示。結果は判定時に保存し、演出で生成や取得をやり直さない。直前の判定欄にも回収内容を表示。
- 戦闘の基礎実効を自分2→4、敵は従来の2倍に調整。装備補正は加算し、STによる減少と最低1個を維持。探索の実効とカード不要の基本1D6は維持。
- 既存セーブの装備・収納・探索と戦闘の武器参照を移行し、進行中戦闘にも新しい実効を適用。乱数・予定・公開位置・アイテムID・既に与えたダメージは保持。

## 0.2.2 の基本探索・ランダム公開・行動数調整

- 開いた物資にカード不要の基本探索（1D6）を追加。難易度5の成功率は約33%。探索行動1回・1時間・頭ST1と体ST1を消費し、手札は消費しない。カード付き探索は基本1D6＋追加（実効−1）D6＋道具補正。鍵・高所などには対応カードが必要。
- 「周辺を探す」は戦闘で距離を1広げる。「鍵を開ける」は距離6で離脱できる。探索カードを入れない18枚デッキも採用できる。
- 敵の予定から知覚の枚数だけランダムな位置を公開。番号と行動順は維持し、公開位置は保存。進行中の演出では実行中・実行済みのカードを追加公開し、解決後は全公開。
- プレイヤーの基礎手札枚数5→8、行動数3→5。野犬・ロボットは手札4→6、行動2→3、拾荒者は手札5→8、行動3→5。HP/STの割合と装備補正は各能力に適用。
- 既存セーブの現在の探索・戦闘ラウンドは維持し、次の見渡し・引き直し・戦闘ラウンドで新しい枚数を適用する。公開位置を持たないセーブには、ゲームの乱数を進めず固定の公開位置を補う。

## 0.2.1 の探索開始とスマホ戦闘画面

- 到着・再訪直後は探索箇所を表示せず、見渡し・引き直しで手札と箇所を一緒に出す。発見履歴と調査済み履歴は保持し、全箇所発見済みの区画でも見渡しから再開できる。
- スマホ戦闘は敵のHP・ST・能力と予定カードを上、自分のHP・ST・能力と手札を下へ配置。場面内の敵も上、自分も下に置き、カードと命中演出は双方の位置を追う。
- 間合いを0〜6の目盛りと自分・敵の駒で表示。移動の解決に合わせて更新し、距離0では同じマスに双方を表示する。
- 探索の背景と、現在地に駐車中のクルマをスマホ・小さいPC画面でも表示。組んでいるデッキにもカード画像を表示する。

## 0.2.0 の共通デッキと探索の盤面

- 拠点で18枚のデッキを自由に配分。基本カードと携行している道具固有のカードを、コピー数の上限内で採用する。武器・防具は維持し、装備変更ではカードを自動追加しない。
- 探索と戦闘で同じ山札と捨て札を使用。探索専用・戦闘専用・兼用カードが同じ手札へ来る。回復カードも両方で使える。
- 箇所カードと手札を選び、実効D6の合計＋道具補正で難易度判定。バール、鍵開け道具、ロープ、ナイフ、箒、スコップに役割がある。失敗した箇所は残り、成功した箇所は再回収できない。
- 独立した「カードを引き直す」コマンド。見渡し・引き直し・カード使用は各1時間。引き直しは未解決箇所を保持して手札と行動回数を更新する。
- 18時〜6時は探索と徒歩の遭遇率が大幅上昇。時計に日没・夜明け・拠点までの徒歩時間と危険度を表示。夜の安全な拠点では食料・水を使って朝6時まで眠れる。
- ボードゲームを意識し、地図、箇所カード、共通手札、時計を盤面へ配置。新しい道具・探索箇所の画像生成素材と探索ダイスのアニメーションを追加。
- 旧0.1系のセーブを自動移行。位置・物資・装備・回収済み箇所と進行中戦闘を保持し、共通デッキを追加する。移行した探索は引き直しで再開する。山札・手札・捨て札の合計と所有道具の参照も検査する。

## 0.1.5 の表示と戦闘演出

- 車は現在地に駐車しているときだけ表示。徒歩で離れた先では表示しない。
- 双方のカードの衝突、カードのない相手への攻撃、６面ダイスの回転と確定出目、命中部位のダメージを順に再生。演出はスキップでき、動きを減らす設定にも対応。
- 敵の行動上限をラウンド開始時に固定し、負傷後に「１回表示・２回実行」となる不一致を修正。予定枚数と実行済み・不発・未実行も表示。
- 区画番号、調査済み件数と箇所名を表示。調査済み候補と別区画の古い候補を処理側で拒否し、旧セーブの候補を整理する。

## 0.1.2 の操作説明

- 行動ボタンのホバー・キーボードフォーカスで、効果・消費・関連する能力・使えない理由を表示。スマホでは長押しで説明を開き、通常のタップで行動する。
- 「周辺を見渡す」は発見する箇所数・探索回数と判断・行動の計算内訳。個々の探索は発見率・良品率・遭遇率と消費を表示。
- 移動・休息・資源・装備・拠点設備・戦闘カードにも説明を追加。説明の表示ではゲーム状態や乱数を変更しない。

## 0.1.1 の画面改善

- PCはブラウザの高さに合わせた１画面レイアウト。長い装備一覧・操作一覧は欄内でスクロール。戦闘の実行・待機・次ラウンドボタンは右欄の下部に固定。

- 既存のセーブを継続利用可能。開始時の内訳が記録されていない旧セーブでは、確定値と現在の参考値を区別して表示。

## ローカルで起動

Node.js 22以上。外部npm依存、CDN、バックエンドは不要。

```bash
npm run dev
```

http://localhost:4173 を開く。ES Modulesを使うので、HTMLファイルを直接ダブルクリックする `file://` 起動には対応しない。

```bash
npm test
npm run build
node scripts/serve.mjs --dist
```

`dist/` はゲームを動かす静的ファイルだけを含む。ソース、テスト、資料、旧プロトタイプは配信しない。すべてのアセット参照が相対パスなので `/scavenger-chronicle/` のようなPagesのサブパスで動作する。

## GitHub Pages

1. 公開リポジトリ `scavenger-chronicle` を作る。
2. このフォルダの中身を `main` に配置する。
3. **Settings → Pages → Build and deployment → Source → GitHub Actions** を選ぶ。
4. `main` へのpush、またはActionsの手動実行でテスト・ビルド・公開が走る。

公開版：[ゲームを遊ぶ](https://zero-error-no-warning.github.io/scavenger-chronicle/)。`main` の更新で自動テスト・ビルド・Pages公開を実行します。

- [カスタムワークフローでのPages公開](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages)
- [Pagesの公開元設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
