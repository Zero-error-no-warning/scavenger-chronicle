# 初版 0.1.0 の検証

実施日：2026-10-04。リポジトリへのpushとGitHub Pages上での公開検証は未実施。

## ゲームルール

`npm test`：29件すべて成功。

出目ごとの部位割り当て、頭と体の防具の使い分け、体HPの超過、STの超過を転送しないこと、柔らかさ下限、防御倍率、能力の減少と最低値、同時移動、移動後の射程判定、射程外のコスト、ST低下による後続ダイス減少、相打ち、離脱距離、計画のコスト不足、ラウンドの二重実行防止、ST０時の待機、セーブ後の同じ戦闘結果、複数修飾子の加算、修飾子の順序と下限、装備変更、探索回数、徒歩と拠点移動、材料消費、休息、次地域への移動、不正セーブ拒否を検査。

追加の自動走行：100種類の乱数シード、３種の敵で計1,174ラウンドを解決し、各ラウンド後のセーブを検査。待機が必要な11ラウンドも操作を継続できた。これはルールの整合性の検査であり、難易度や戦術の評価ではない。

## ブラウザ操作

ローカルのChromiumで、初期表示、探索箇所の発見、探索と遭遇、装備変更、資源の預け入れ、収納設備の追加、敵の予定表示、計画選択、行動解決、JSON書き出しを操作。JavaScript実行エラーなし。

再読み込みの前後で戦闘の手札が維持されることを確認。ST０・有料手札のみの状態でも待機で次ラウンドに進む。壊れたJSONの読み込みを拒否し、保存済みデータを維持する。

## 静的ビルドとレイアウト

`npm run build` で `dist/` を生成。GitHub PagesのプロジェクトURLと同じ `/scavenger-chronicle/` のサブパスへビルドを置き、HTML・CSS・ES Modules・アイコンを読み込めることを確認。HTTPエラーとJavaScript実行エラーなし。

画面幅360・390・768・1024・1440pxでページ全体の横はみ出しなし。手札は意図的な横スクロール。PCの探索・拠点・装備・戦闘、390pxの探索・戦闘をスクリーンショットで目視確認。

- 実機Android／iOS／Safariの操作、音声、保存制限。
